# Exploration atlas — production brief

Generated with the built-in image generation tool, using `modules.webp` as the style reference. Source PNG: 1774 × 887, alpha preserved; delivered as `exploration-sites.webp`, WebP quality 88. Native rendering uses measured source rectangles in `design.js` rather than assuming perfectly uniform generated gutters.

Rows: vehicles, ruined houses, abandoned shops. Each row has five active variants followed by one depleted state. Existing seeded variants, resource drops, durability and regeneration timings remain in the game code. Active sites participate in the existing touch occlusion and x-ray system; depleted sites use ground picking.

## Final prompt

Use case: stylized-concept. Asset type: production transparent isometric sprite atlas for the Korean survival mobile game 'Tap to City'. Input image 1 is a STYLE REFERENCE only: match its confident hand-inked outlines and restrained painted textures, simplify small details for legibility at 60 pixels. Create one wide 2:1 atlas, exactly SIX equal columns and THREE equal rows, all 18 square cells, no labels or grid lines. All cells have transparent background, generous 10% empty margin, every object's ground contact baseline aligned at 86% of its own cell height. Consistent orthographic isometric 2:1 ground perspective, roofs visible, no exaggerated perspective. Each object fits entirely in its cell, nothing touches or crosses cell boundaries.

# 전체 QA 스크립트 (2026-10-11)

플레이라이트로 게임을 띄워 점검한다. `dist/`에 게임 사본과 테스트 진입점 `_t.html`(window.__ev 노출)을 만든 뒤 실행한다.

- `tqa.py [포트] [화면폭] [UA]` — 저장본(early/mid/late) × 동네 4곳 × 모든 시트·탭·생존자·펫·모달·노선·링 메뉴를 열어 깨진 글자(undefined/NaN 등), 가로 넘침, 안 뜨는 그림, 콘솔 오류를 모은다.
- `tdata.py` — 장비·생존자·자원·노선·펫·랜드마크 표의 빠진 연결(아이콘, 효과 이름, 재료, 흔적 물건, 그림)을 검사한다.
- `tplay.py` — 새 게임과 늦은 저장본으로 동네 4곳을 빨리 감기 자동 플레이하며 오류를 모은다.

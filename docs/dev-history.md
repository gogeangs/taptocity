## 3단계 · 앱 전용 콘텐츠와 다듬기 (10/17 ~ 10/19)

- **긴장감**: 막지 못한 밤의 부상, 정답 없는 선택, 억울한 의심과 사과, 더 어두운 밤
- **시즌 1 다듬기**: 새 동네 반복 줄이기, 막히면 생기는 보급 더미, 증축 비용 조정
- **장기 콘텐츠**: 끝없는 지하와 보스, 그날 밤의 기록 조각 12편, 오늘의 할 일 7일 연속, 인연
- **QA 자동 플레이**: 사람처럼 하는 봇이 새 게임 3판을 엔딩까지, 막히는 시간까지 기록
- **웹툰 컷**: 사건·합류·고백 장면 4칸 컷 (ChatGPT 그림, 여러 번 다시 그림)
- **대사 점검**: 순례 경상도 사투리, 진 반말, 나이에 맞는 호칭

## 4단계 · 출시 준비와 실기기 피드백 (10/20 ~ 10/21)

- **TestFlight 빌드 100~106**: 100은 시험 프로그램이 잘못 올라가 만료 처리 후 원인 수정, 101~106은 대표님 휴대폰 피드백을 매번 반영
- **실기기 피드백 14가지**: 텐트·건물·폐허 터치, 겹친 모듈, 효과음 끊김, 재 괴물 그림, 닫힌 벙커, 지하 상인 버튼, 대화 버튼 크기, 초상 자르기 등
- **UI 점검 10가지 · UX 개선 6가지**: 뒤질 곳 표식, 누름 반응, 닫기 버튼 통일, 돌아왔을 때 요약 카드, 알림 정리, 확대 기억
- 개인정보처리방침에 앱 오류 자동 보고 문단 추가
- 일하는 방식: **기록만 해 두고 "진행해줘" 할 때 반영**

## 출시 방법 (참고)

- **iOS**: GitHub `Native iOS` 워크플로 수동 실행(upload 켬) → TestFlight 확인 → App Store Connect에서 새 버전에 빌드 연결 후 제출

- 빌드 번호는 `native/pubspec.yaml`의 `+N` (다음은 108)

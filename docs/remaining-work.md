## 4. 알고 있지만 고치지 않은 것 (영향 작음)

- 점검용 화면 사진에서만 ❄(한파), ≋(강풍), 동네 이모지(💧🏭🏫)가 네모로 나옴. 실제 휴대폰에서는 정상. 웹 데이터에서 가져오는 값이라 그대로 둠.
- 웹툰 컷 `join_jin_choice` ④칸(진이 떠나는 결말)은 쓰지 않음. 게임에서 진은 항상 남음. 시즌 2에서 쓸 수 있게 저장소에 남겨 둠.
- 웹 버전 지하 칸 배치 버그(칸이 모자라면 겹침)는 웹에 깊은 층이 없어 고치지 않음. 앱은 고침.

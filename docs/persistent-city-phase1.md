# 영구 도시 / 자유 건설 1차 구현

개발 브랜치: `dev/persistent-city-phase1` · 기준 main: `07910f5c27fec641813ca62b22ebe1774c291060`

## 실행

웹 게임에서 **쉘터 → 건설 → 우리의 도시 · 자유 건설**을 선택한다. 건물을 고른 뒤 지도의 왼쪽 위 기준 칸을 누르고 미리보기를 확인한 다음 확정한다. 개척 버튼을 누르면 기존에 밝혀진 땅의 상하좌우 칸을 두드릴 수 있다. 동쪽 구역의 서쪽 끝은 중심 거점의 동쪽 끝과 연결된다. 구역 버튼으로 미개척 구역을 미리 볼 수 있다.

## 구현 범위

- 중심 거점과 동쪽 구역 각각 25×25, 총 1,250타일. 첫 5×5만 개척된 상태로 시작한다.
- 시드 기반 지형, 물길, 부분 개척 진행, 구역 경계 연결, 건물 좌표 및 단계가 `S.city`에 유지된다.
- 주거·농장·작업장·감시탑: 배치 미리보기, 회전, 확정/취소, 무료 이동, 최대 3단계 강화, 2회 확인 철거. 건물 전체 바닥의 개척·지형·겹침·경계를 검사한다.
- 주거의 침상과 농장/작업장의 생산량을 기존 게임 계산에 연결했다. 감시탑은 같은 구역 반경 4칸의 개척을 돕는다. 주민 침상이 부족해지는 주거 철거는 거절한다.
- 자재와 도시 변경을 같은 저장본으로 기록한다. 저장 실패 시 해당 작업 전체를 취소한다. 기존 저장 코드는 그대로 읽으며, 도시 필드가 있는 저장 코드는 별도 검증한다.
- 기존 이주 실행에서도 도시 필드는 유지한다. 기존 탐사 지도, 배치 모듈, 생존자 데이터는 별도 구조로 보존한다.
- Canvas는 조작할 때만 다시 그린다. 드래그/터치 스크롤, 24~64px 확대/축소, 중심 이동, 방향키/Enter 입력, 상태 안내 및 기본 dialog 포커스 처리를 제공한다.
- 서비스 워커 캐시 버전을 갱신하고 새 JS/CSS를 오프라인 목록에 추가했다.

## 테스트용 수치 (확정 밸런스 아님)

| 건물 | 크기 | 목재 / 고철 | 개척 해금 | 효과 / 단계 |
|---|---|---|---|---|
| 주거 | 2×2 | 20 / 10 | 시작 | 침상 2 |
| 농장 | 2×2 | 15 / 5 | 36칸 | 식량 2/분 |
| 작업장 | 2×2 | 10 / 20 | 60칸 | 목재·고철 각 1/분 |
| 감시탑 | 1×2 | 15 / 15 | 90칸 | 개척 타격량 1 |

강화 비용은 건설비 × 도달 단계이다. 철거 환급은 없다. 안전/주의/위험의 기본 개척 횟수는 2/4/6회다. 물을 제외한 신규 개척 보상은 목재 2, 고철 1이며 창고 여유만큼 지급한다. 기존 생산 보정(예: 건설 자재 +30%)이 도시 생산에도 적용된다.

## 검증

```sh
node --test tests/qa-regressions.cjs tests/city.test.cjs
node --check city-core.js
node --check city-view.js
node tests/make-city-browser-test.cjs ../work/city-browser.html ../taptocity/
```

- Node 회귀/도시 테스트 54개 통과: 저장 호환, 경계 연결, 중복 보상 차단, 전 바닥 충돌 검사, 해금, 강화, 철거, 잔고 보존, 저장 실패 원자성, 잘못된 도시 저장 거절.
- Chrome에서 실제 `index.html` 게임 클로저와 DOM을 사용하는 통합 테스트 12개 통과: 진입 버튼, 미리보기 취소, 건설/침상/저장, 겹침 차단, 이동/회전, 개척, 재진입, 불러오기, 잘못된 저장 거절, 기존 이주 시 도시 유지.
- 생성된 브라우저 테스트 HTML은 로컬 QA용이다. 독립 경로에서 실행하며 해당 경로의 테스트 전 저장본을 복원한다. 클라우드 접속/서비스 워커 등록은 테스트 생성 시 제거한다.
- 터치 실기기 조작, 서비스 워커 오프라인 재접속, 장시간 경제 밸런스는 추가 실기기 검증이 필요하다.

## 후속 범위

이번 변경은 웹 게임에서 검증 가능한 기능 기반이다. Flutter `native/`, TestFlight 및 운영 main은 변경하지 않는다. 기존 40×40 탐사 맵을 이번 단계에서 강제로 변환하지 않고, 도시 기능을 쉘터에서 여는 형태로 연결했다. 도시 건물은 기능 확인용 도형으로 표시하며 최종 아트는 별도 승인 후 적용한다. 낮/밤·재폭풍을 새 도시의 위험도에 연결하기, 생존자 도시 내 배치, 이야기 보상, 전체 도시 성장 연출은 다음 단계다.

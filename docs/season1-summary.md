## 3. 이야기

### 3-1. 로그라인과 장르

재가 하늘을 덮은 지 **43일째**(게임 표기 '마흔세 날'), 낡은 랜턴 하나를 든 "등불지기"가 무너진 동네에서 사람들을 모은다. 굶주림과 재폭풍, 약탈자, 그리고 쉘터 안의 누군가에 맞서 첫 등불을 켜기까지의 생존기.

| 항목 | 내용 |
| --- | --- |
| 장르 | 포스트 아포칼립스 생존 군상극 |
| 톤 | 따뜻하지만 쓸쓸함. 희망은 크게, 대가는 분명하게 |
| 주인공 | 쉘터 사람들 전체. '나'(등불지기, 아버지를 찾는 30대 초반 남자)는 사람을 잇는 중심 |
| 매체 | 게임(시즌 1) → 웹드라마(9:16, 2분 × 60화) → 웹툰·애니메이션 |
| 시즌 1 주제 | "어떻게 살아남을까?" → 시즌 2 "누구를 믿고, 누구와 이어질까?" |

**시즌 1에서 닫히는 것:** 우리 동네 등불 탑에 첫 불 · 흩어진 생존자들이 공동체가 됨 · 재혁의 고백과 미영과의 재기.

**시즌 1에서 열어 두는 것:** 03:11~03:14 사라진 3분 · 쉘터 안 사건의 범인 · 사라진 아버지의 생사 · 탑에 답한 먼 불빛들 · 엔딩 밤 03:11 송출을 끊은 사람 · 먼 불빛이 3·1·1로 깜빡인 이유.

### 3-2. 세계관

도시 외곽 발전소는 핵융합으로 인공 태양을 만드는 **'등불 계획'** 실험로였다. 그날 실험로가 폭주하자 걸러지지 않은 빛이 공기 중 먼지를 굳혀 **재**가 되었고 하늘을 덮었다. 재는 강한 빛에 끌리고, 제대로 걸러진 등불 계획의 빛에만 다시 풀린다.

**세계의 규칙**
1. 재는 늘 내린다. 밤에는 재폭풍이 되어 밝힌 땅을 다시 덮는다.
2. 등불 계획의 빛(주인공의 랜턴, 등불 탑)만 재를 녹인다. 보통 불빛은 길만 비춘다.
3. 재는 강한 빛에 모인다. 사흘에 한 번 재가 뭉친 '재 괴물'이 불빛을 향해 밀려온다.
4. 등불이 클수록 사람도 모이지만 재와 약탈자도 부른다.
5. 재는 전파도 먹는다. 무전·위성·헬기가 먹통이라 구조대가 오지 못한다. 재가 얕은 날·가까운 거리에서만 약하게 닿는다.

| 용어 | 뜻 |
| --- | --- |
| 재 / 재구름 / 재폭풍 | 그날 이후 내리는 회색 가루 / 땅을 덮은 재의 층(랜턴으로 걷음) / 밤마다 부는 재 바람 |
| 재 괴물 | 대형 재폭풍 밤, 강한 빛에 끌려 뭉친 재 덩어리. 의지 없음. 걸러진 빛에 닿으면 흩어짐 |
| 등불 계획 | 핵융합 인공 태양 실험. 1990년대 국책 연구 → 1997년 IMF로 중단 → 사고 3년 전 비밀 재개 |
| 랜턴 LP-001 | 겉은 기름 랜턴, 속은 등불 계획의 '작은 태양'. 첫 시제품. 아버지가 20년 넘게 간직. 시리즈의 모든 열쇠 |
| 등불지기 | 랜턴을 든 주인공의 별명 |
| 쉘터 | 텐트 → 판잣집 → 컨테이너 → 요새 → 불빛의 도시 |
| 등불 탑 | 실험로의 심지를 담아 랜턴 불빛으로 깨워 하늘로 쏘는 탑. 아버지의 설계. 시즌 1의 목표 |
| 제어실 | 발전소 출력을 다루던 방. 심지의 빛 덕에 재가 들어오지 못한 유일한 방. 미영이 버틴 곳 |
| 분소 | 등불 계획의 다른 연구소. 사막·공단·설산에 멈춘 탑이 있다(시즌 2 '등불망') |
| 까마귀 | 쉘터를 잃고 떠도는 약탈자 무리. 벽에 검은 새 표식 |
| 사라진 3분 | 사고 당일 03:11~03:14. 기록이 비어 있다 |
| 사막 | 서해안 거대 간척지에 재와 모래가 뒤섞인 벌판을 부르는 별명. 급유탑은 간척지 항만 급유 시설 |

발전소는 원자로가 아니라 인공 태양 실험로라 오래가는 방사능 오염이 없다. 철호의 무너진 건물, 설화의 막힌 예보, 은호의 보류된 방송은 모두 **'안전보다 일정'**이라는 같은 줄기다(실제 지명·사건명은 쓰지 않는다).

### 3-6. [기밀] 진짜 빌런: '나'

- **두 인격:** 낮의 나(리더, 아버지를 찾음, 다른 인격을 모름) / 다른 인격(1997년 무렵 생김, 그날 밤 제어실에서 처음 깨어남, 이후 **새벽 3시 11분**에 깨어남). 인격이 바뀌면 기억을 잃는다.
- **방아쇠:** 4장에서 은호가 고친 **밤의 라디오**가 다른 인격을 완전히 깨운다. 재가 얕은 밤에만 라디오가 잡히므로 수상한 밤도 그런 밤에만 일어난다(시즌 2의 비극).
- **원칙:** 그날 밤의 진실에 닿는 '연결'을 끊는다(무전기, 확성기, 녹음, 안테나…). 결국 '나'가 '나'를 막는다. 동기는 시즌 2.
- **랜턴:** 다른 인격도 랜턴을 쓰지만(기름 줄어듦, 뜨거운 갓, 둥근 그을음 고리, 화상) **깨거나 버리지 못한다** — 아버지가 쥐여 준 물건이라 넘을 수 없는 선. 그래서 탑을 막지 못하고 "불은 오래가지 않아." 경고만 남긴다.
- **흔적 장치:** 시간 공백("깨어 보니 3시 20분"), 랜턴 상태, 기억 안 나는 말, 열쇠는 늘 리더의 허리춤, 쪽지 글씨가 낯익음.
- **금지선:** 시즌 1에서 다른 인격이 직접 말하거나 누가 '나'를 범인이라 말하는 장면 없음. 의심은 "제가 잘못 봤겠죠" 수준까지. 단서 하나로는 '나'를 가리킬 수 없게(둥근 그을음은 인두·납땜·용접과 함께).
- **표현:** 다중인격을 '원래 위험한 사람'으로 그리지 않는다. 낮의 나는 끝까지 공감 가는 인물.
- **영상 문법:** 화면은 낮의 '나'의 기억. 다른 인격이 깨는 순간 0.5초 흔들림 → '딸깍' → 블랙 → 다음 컷은 아침이나 3:20. 다른 인격의 목소리는 블랙 직전 독백 끝 한두 단어만 낮고 느린 존댓말 결로.
- **미영:** 8장 합류 첫날부터 '나'를 알아봄. 말하지 않는 이유는 시즌 2. 9장 "이 랜턴, 누구한테 받았어요?" → "…그렇군요."
- **은호와 미영:** 한 프레임에 담지 않는다. 피하는 쪽은 은호(죄책감).

### 4-9. 안내·UX 원칙 (시즌 1에서 정한 것)

- **새 기능 안내 카드**(15종): 그림·무엇인지·'이렇게 써요' 단계·팁, '보러 가기'는 그 화면을 열고 해당 버튼을 짚음. 일지 → 안내서 '열린 기능 안내'에서 다시 보기.
- **튜토리얼 뒤 온보딩:** 카드 '마흔세 날 뒤, 재 속의 텐트'(할 일 5가지) + '화면 둘러보기' 코치 투어 5곳.
- **글 대신 화면으로:** 보상·소모 숫자는 자원 아이콘+숫자로(예: '고철 +34' → [아이콘]+34).
- **설명은 한 곳에만:** 기능 설명은 안내 카드가 기준. 알림은 한 줄 + '안내 보기 ›'. 반복 설명은 처음 2번만.
- 가벼운 목표는 대화창 대신 짧은 이야기 알림. 대화 장면은 이야기의 큰 마디에만.
- 터치 영역 최소 32~36px, 켜기/끄기 줄은 줄 어디를 눌러도 토글.
- 스킬 초상은 늘 같은 자리(안내 말풍선이 겹치면 말풍선이 위로 비켜 점선으로 가리킴).
- 설정: 음악·소리·진동·움직임 줄이기·절전 모드·큰 글씨·클라우드 저장·피드백 보내기·플레이 안내·개인정보 처리방침.

### 4-10. 소리와 음악

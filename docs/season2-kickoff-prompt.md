## 3. 시즌 2 대전제 (내가 정한 것)
- **시즌 1(장면·대사·설정)은 절대 고치지 않는다.** 시즌 2는 시즌 1 엔딩 뒤에 이어 붙인다.
- 게임과 웹드라마는 **같은 줄기**로 간다. 중심축은 **'나'의 정체**.
- 이 게임은 스토리와 인물의 대사가 가장 중요하다. 말투는 바이블의 인물별 말투 표를 지킨다.
- 결국 수익화가 목표다(혼합형 검토: 본편 해금·광고·꾸미기 등). 유료화 방향은 아직 미정이라 시즌 2 기획 안에서 함께 제안해 줘.
- 시즌 2 방향 초안(정리 문서 3-13): '살아남기' → **'연결하기'**(다른 분소의 탑을 이어 등불망), 사라진 아버지, 사라진 3분, 까마귀(시즌 1 선택에 따라 적·거래·동맹), 결말을 완전히 닫지 않기. 열린 질문: 엔딩 밤 송출을 끊은 사람, 먼 불빛 3·1·1과 아버지 흔적, 네 번째 동네 이후.

## 4. 일하는 방식
- **기획은 문서로 보여 주지 말고 대화에서 바로바로 질문해 줘.** 결정이 필요한 건 한 번에 하나씩, 선택지와 네 추천을 함께.
- 내가 새로 말하는 업무는 **바로 반영하지 말고 남은 업무 목록(`docs/remaining-work.md` 0번 · 프로젝트 `claude/남은-업무.md`)에 기록만** 하고, 내가 "진행해줘"라고 하면 그때 반영.
- 기획이 확정되면 바이블·정리 문서·대본에 반영하고 프로젝트 문서도 갱신.
- 스토어 업로드·심사 제출·출시는 내가 확인한 뒤에만. 비밀 값(키·비밀번호)은 내가 직접 넣는다.

## 5. 개발할 때 알아 둘 것 (기획 확정 후)
- 로컬에 Flutter 없음 → **CI로만 확인**. 결과는 `gh api repos/gogeangs/taptocity/check-runs/<job id>/annotations` 로 읽는다.
  - `Native`(push 시 자동): 분석·단위 시험(저장 호환 `save_compat_test`, 엔진 회귀 `web_parity_test`, 시스템 시험)·자동 플레이 3판(`qa-play.txt`)·화면 394개 훑기·화면 사진(`native-play/shots/`)·APK
  - `Native iOS`: 시뮬레이터 점검, `upload=true`로 TestFlight. `ASC builds`로 처리 상태 확인
  - `Play`: `upload`(서명된 AAB → internal) / `promote`(versionCode → production)
  - `Tag`: 출시 꼬리표
- 게임 데이터 원본은 `native/lib/data/web_data.g.dart`(직접 고침). `tool/gen_data.cjs`는 얼려 둠.
- 커밋: `git -c user.name="gogeangs" -c user.email="ceo@itso.co.kr" commit` 후 `git pull --rebase && git push` (main 강제 푸시·이력 수정 금지).
- 화면 사진 비교(골든)는 쓰지 않음 — 지도 위 사람·불티·시계 때문에 매번 달라짐.

탭투시티 개인정보 처리방침

시행일 2026년 10월 9일 · 주식회사 프로젝트서티즈

탭투시티(이하 "게임")는 플레이어의 개인정보를 소중하게 생각합니다. 이 문서는 게임이 어떤 정보를 다루고, 어디에 저장하며, 무엇을 하지 않는지를 설명합니다.

1. 게임이 저장하는 정보

진행 상황은 플레이어의 기기에 저장되고, 이어하기를 위해 같은 내용이 클라우드(구글 Firebase)에 백업됩니다.
  • 저장되는 것: 쉘터·생존자·자재 같은 게임 진행 상황, 플레이어가 직접 입력한 등불지기 이름과 반려동물 이름, 소리·음악·큰 글씨 같은 설정.
  • 저장되는 곳: 플레이어의 기기(브라우저의 로컬 저장소)와, 3항의 클라우드 저장소.
  • 요구하지 않는 것: 게임은 이름·전화번호·위치·연락처·사진 등 개인을 알아볼 수 있는 정보를 요구하거나 수집하지 않습니다. 이메일 주소는 플레이어가 구글 계정 연결을 선택한 경우에만 계정 식별을 위해 사용됩니다.

2. 수집하지 않는 것

  • 광고를 싣지 않으며, 광고 식별자를 사용하지 않습니다.
  • 이용 통계·분석 도구(애널리틱스)를 사용하지 않습니다.
  • 기기 권한(카메라, 마이크, 위치, 연락처, 저장공간)을 요청하지 않습니다.
  • 개인정보를 제3자에게 판매하거나 제공하지 않습니다.

3. 클라우드 저장

게임은 진행 상황을 잃지 않도록 구글의 Firebase 서비스(서울 리전)에 다음 정보를 저장합니다.

  • 게임 진행 상황(위 1항의 저장 데이터)과 저장 시각
  • 기기를 구분하기 위한 익명 식별자(무작위 문자열로, 개인을 알아볼 수 없습니다)
  • 플레이어가 설정에서 구글 계정 연결을 선택한 경우에만, 계정 식별자와 이메일 주소

저장된 데이터는 본인의 식별자로만 읽고 쓸 수 있으며(접근 규칙으로 강제), 전송 구간은 암호화됩니다. 다른 플레이어와 공유되거나 광고·분석에 쓰이지 않습니다.

4. 외부 서비스

  • Google Fonts: 글꼴을 불러오기 위해 구글 서버에 접속하며, 이 과정에서 기기의 IP 주소가 구글에 전달될 수 있습니다. 구글의 처리 방식은 구글 개인정보처리방침을 따릅니다.
  • GitHub Pages: 게임은 GitHub Pages에서 제공되며, 접속 기록은 GitHub의 정책에 따라 처리됩니다.
  • Firebase: 3항의 클라우드 저장에 사용합니다. Firebase 개인정보 보호

5. 어린이의 개인정보

게임은 개인을 알아볼 수 있는 정보를 요구하지 않으며, 익명 식별자만으로 동작합니다. 구글 계정 연결은 선택 사항이며, 만 14세 미만 어린이는 보호자의 계정과 동의 아래 사용해야 합니다.

6. 보관과 삭제

  • 기기에 저장된 데이터는 플레이어가 설정의 '새 게임'을 누르거나 게임(또는 브라우저 데이터)을 삭제하면 지워집니다.
  • 클라우드 데이터와 계정 연결 삭제: 게임의 설정 → 클라우드 저장 → '클라우드 데이터 삭제'를 누르면 서버에 저장된 진행 상황과 계정 연결(익명 식별자 또는 구글 연결)이 즉시 삭제됩니다. 앱을 지웠거나 접근할 수 없는 경우, 사용한 구글 계정 주소를 적어 아래 연락처로 보내 주시면 7일 이내에 삭제합니다.
